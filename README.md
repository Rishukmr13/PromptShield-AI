# PromptShield AI
Educational prompt-safety red-team workbench. **Current prototype is a static heuristic demonstration, not an external LLM/API tester.**
## Run
Open `code/app.html` in a browser. No API key or install required.
## Modules
- Attack template generation by category
- Manual target response input
- Heuristic risk evaluation and canary detection
- System prompt hardening suggestion
## Repository contents
`prompts/` prompt drafts and final; `test-data/` synthetic test cases; `docs/` report and supporting document.
